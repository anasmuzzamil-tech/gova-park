GOVAPARK — ÉTAPE 18
Hub stationnement, paiement, réservation, voiturier et accessibilité.

Démarrage :
1. npm install
2. npm run dev

Nouvel espace : /mobilite
La navigation principale et la carte proposent un accès à cet espace.

Cette étape référence les opérateurs et ouvre leurs services externes. Elle ne réalise pas les paiements ou réservations tierces. Une intégration API complète exige des accords commerciaux, identifiants, environnements de test et validations partenaires.

La préférence CMI est enregistrée localement uniquement. Elle ne vérifie pas la carte et ne remplace pas les règles de la commune ou les modalités de ticket virtuel.

Voir ETAPE_18_HUB_STATIONNEMENT_ACCESSIBILITE.md pour les détails et limites.
