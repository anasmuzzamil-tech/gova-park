GOVAPARK — LIVRAISON DE DEVELOPPEMENT

Cette version conserve le projet source transmis et ajoute :
- un tableau de bord propriétaire alimenté par une route API sécurisée ;
- des contrôles plus stricts lors du refus d'une demande ;
- des textes explicites sur l'absence de paiement réel ;
- un parcours de réservation de démonstration sans saisie de carte bancaire ;
- un guide de démarrage et une feuille de route de mise en production.

ATTENTION :
Le paiement réel n'est pas connecté. Aucune carte bancaire n'est débitée et aucun propriétaire n'est payé. Les montants affichés sont des calculs internes de démonstration.

Validation : l'installation des dépendances a dépassé le délai disponible dans l'environnement de préparation. La vérification TypeScript locale n'a donc pas pu démarrer faute des types Node et Vite. Exécuter npm ci, npm run check, npm run lint, npm run build et npm test sur ordinateur avant toute mise en ligne.

ETAPE 9 — GUIDAGE ET LIBERATION DE PLACE
- Itineraire routier OSRM dessine sur la carte.
- Places privees disponibles a moins de 900 m du trajet.
- Actions itineraire et reserver depuis le marqueur.
- Alertes de proximite a 800 m apres consentement notification.
- Plaque facultative sur une reservation privee, non publique.
- Detection GPS volontaire du depart annonce : deux positions fiables et eloignement >= 120 m ; le signalement devient libre potentiel pendant 15 minutes.
- Migration requise : ALTER TABLE reservations ADD COLUMN vehiclePlate VARCHAR(12) NULL;
- Limites : GPS en arriere-plan non garanti sur navigateur ; OSRM public pour prototype uniquement ; la plaque ne geolocalise jamais un vehicule.
